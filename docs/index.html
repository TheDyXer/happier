Install

  1. Tap Download APK on your phone.
  2. Open the downloaded file. If Android asks, allow your browser to install apps.
  3. Open Happier and log in.

Keep it updated

Automatically, with Obtainium

Install Obtainium, tap Add app, paste https://github.com/TheDyXer/happier and tap Install. Installed this way, it updates Happier in the background.

Already installed from the browser

Obtainium still finds new versions, but each update needs a tap.

Log in

Accounts on happy.colombus.fun are separate from accounts on Happy's hosted server. Pick the case that fits:

First time on this server

Tap Create account.

Already logged in on another device

On that device: Settings → Account → Link New Device, then scan the code this app shows.

Same phone as the official app

In the official app: Settings → Account → Secret Key (tap to copy). In this app: Restore an existing account → Use a secret key instead, then paste.

Connect your computer

  1. Install the Happy command-line tool on the computer that runs Claude Code or Codex: 
    npm install -g happy
  2. Create ~/.happy/settings.json (Windows: %USERPROFILE%\.happy\settings.json) with: 
    { "serverUrl": "https://happy.colombus.fun" }
  3. Run happy, choose Mobile App and scan the code with this app.

A model only works if the Claude Code or Codex on your computer knows it, so keep them updated.
